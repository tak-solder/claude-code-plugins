# deny-claude-branch

Claude が `claude/` プレフィックスのブランチへ `git commit` することを防止する Claude Code プラグインです。

## 目的

Claude が誤って `claude/` プレフィックスの付いたブランチ(Claude Code が自動生成することのあるブランチ名など)にコミットしてしまうことを防ぎます。

## 仕組み

`PreToolUse` フックで `Bash` ツールの実行をフックし、以下の条件をすべて満たす場合にコミットをブロックします。

- 実行しようとしているコマンド文字列に `git` と `commit` の両方が含まれる
- コマンド実行時のカレントディレクトリにおける Git のカレントブランチ名が `claude/` で始まる(カレントディレクトリが Git リポジトリ外の場合は `CLAUDE_PROJECT_DIR` のリポジトリを対象にする)

ブロックされた場合、Claude には以下のメッセージが返されます。

> claude/* のブランチ使用禁止です。現在の作業に適した作業ブランチ名に変更してからコミットしてください

## 構成

```
deny-claude-branch/
├── .claude-plugin/

├── hooks/
│   ├── hooks.json
│   └── scripts/
│       └── check-branch.sh
└── README.md
```

## 注意事項

- ブランチ判定はコマンド実行時の `cwd` を基準に `git rev-parse --abbrev-ref HEAD` で取得しています。`cwd` が Git リポジトリ外(`/private/tmp` など)の場合は、環境変数 `CLAUDE_PROJECT_DIR` のリポジトリで判定します。
- コマンド内で `git -C <path> commit` や `cd <path> && git commit` のように別ディレクトリのリポジトリを対象にした場合も、判定は `cwd` のリポジトリのブランチで行います。対象リポジトリが `claude/` ブランチでも検知できず、逆に `cwd` 側だけが `claude/` ブランチだと、別リポジトリへのコミットが誤ってブロックされます。
- コマンド文字列に `git` と `commit` が含まれるかどうかで広く検知するため、`git commit` 以外の意図しないコマンド(例: コメント文字列にたまたま両方の単語が含まれる場合など)でも判定対象になることがあります。
- 検知対象のプレフィクスは `claude/` 固定です。プレフィクスの設定を変更している場合は検知できません。
- コマンド文字列の字面だけで判定するため、エイリアスや関数経由での `git commit` 実行、大文字小文字が異なる表記などは検知をすり抜けることがあります。本フックは簡易的な抑止であり、完全な防止策ではありません。
